# Chart Builder

A phone-installable version of Chart Builder. Upload a CSV or type a table, see a summary, and build bar, pie, and line charts. Data stays in the browser on that phone. No account.

## Install on a phone

1. Open the site in Chrome on Android, or Safari on iPhone.
2. Android: tap **Install app** on the home screen, or use the browser menu and choose **Install app** / **Add to Home screen**.
3. iPhone: tap **Share**, then **Add to Home Screen**.
4. Open **Charts** from the home screen. It launches full screen and keeps working offline after the first visit.

## Deploy on Vercel

Import this repository in Vercel. Leave the framework preset as **Other**, the root directory as the repository root, and the build command empty. Vercel serves `index.html` as a static site.

## Try the sample

On the home screen, tap **Load sample CSV**, choose **Bar**, keep **Month** as the category, select **Revenue** and **Cost**, then tap **Show chart**.
